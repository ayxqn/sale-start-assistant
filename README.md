# 开售助手

一个独立安装的安卓小应用。填好 B 站官方活动链接和开售时间，保持助手在前台，到点进入官方活动页，再由你自己下单、核对金额和付款。

**这是进场辅助工具，不是自动抢单器。** 它不提交订单、不自动付款，也不保证买到。只支持 Android 8.0 及以上，不支持 iPhone、iPad 或 iOS。

## 当前版本

1.0.0 内测版，2026 年 9 月 30 日。原生 Java，没有第三方运行库；不需要 AutoJs6、电脑、USB、Root、无障碍服务或屏幕捕获。

已完成编译、30 项链接和时间逻辑检查、APK 签名验证及安装包权限检查。**尚未完成真机安装、官方 App 跳转和不同手机系统的验收，也没有做真实购买测试。** 暂不标为已全面验证的正式版本。

## 安装与使用

1. 从仓库的 Releases 下载 APK。仓库当前为私有，需要所有者授权才能访问。核对同一发布页的 SHA256SUMS.txt，别安装别人修改后转发的同名文件。
2. 用安卓手机打开 APK，按系统提示，仅给当前文件来源临时允许安装权限。安装后可以关掉该来源权限。不要为安装关闭系统防护；系统若报恶意软件或证书异常，停止安装。
3. 安装官方 B 站 App，在里面登录**自己的账号**。助手不提供登录框，不读取密码、Cookie、短信、指纹或微信资料。
4. 填写 `/blackboard/` 开头的 B 站官方活动页 HTTPS 链接，删除问号或井号之后的分享参数。不要填写收银台、支付链接或含账号信息的链接。
5. 点“先打开官方页，检查账号”，确认活动仍有效、自己有资格，商品、金额和权益没有看错。回到助手，按**北京时间**选择日期和时间。
6. 开售前两小时内点“开始倒计时”。保持助手前台、亮屏、手机解锁；到点只进入官方页一次。需要购买时由你手动操作，付款前再核对账号、商户和金额。

“10 秒演练”只在本机倒计时，不联网、不开网页，也不下单。随时点“停止倒计时”即可停止。

## 换账号怎么处理

去官方 B 站 App 退出原账号，再登录要使用的账号。回到助手前，重新打开活动页核对一次。助手不会导入开发者账号，也不会把活动设置当成账号信息；卸载助手不会退出官方 App 或取消订单。

## 几件容易误会的事

- 切到后台、锁屏、来电占据页面或进程被系统结束，等待会停止，**不会自动恢复**。返回后重新启动；没连电脑不影响使用。
- 打开助手并不等于开始等待。必须点“开始倒计时”，看到“正在等待”。
- 开售时间由用户填写，没有活动服务器校时。倒计时显示精细不代表服务器接收准确，更不代表库存保证。
- 目前只适配大陆版官方 B 站 App 的打开入口。国际版、HD 版、新版入口、系统应用跳转设置都可能不同。请先试跳转；打开请求成功不代表正确页面已显示。
- 活动页按钮不更新时，应在官方 App 内按正常方式刷新或重新进入，不要一直停在旧页面等待。助手不会刷新、连点或请求购买接口。
- 老活动、同价不同套餐、赠品兑换期限、账号资格、限购、退款和自动续费，都要在官方规则里核对。历史“178 元五份年卡”是不同平台年卡组合，并非五年 B 站会员；本应用不承诺该活动目前仍在售。

## 隐私与安全

安装包没有申请任何 Android 权限，包括联网、无障碍、截图、读写外部文件、位置、通讯录、摄像头和麦克风。没有广告、统计、远程配置或自动更新 SDK。

助手只把活动名称、公开活动链接、开售时间和已读说明保存在自己的本机私有目录。这些普通设置没有额外加密，因此不要在名称里写密码或个人资料。已禁用应用备份；Root、被入侵的手机或厂商特殊迁移机制不属于可以保证的保护范围。打开官方页后，官方 App 或浏览器会按自己的隐私政策处理数据，不能把它们的联网行为理解成助手不联网的承诺。

点“清空本地设置”会停止等待并删除上述设置；卸载也会清除本应用的数据。无账号凭据需要在助手里退出或解绑。

## 为什么没有沿用旧接口抢购

旧代码是针对一次特定活动的个人实验，依赖未公开保证稳定的下单接口，还需要从电脑导入会话和维护历史订单状态。旧版本没有成功取得限量目标套餐，不能直接包装成可靠的公众产品。新版本独立重写，不使用旧账号、订单、图片素材或私有会话；移除了自动下单、持续重试、直接微信交接、普通套餐测试下单、USB 导入和复杂测试菜单。原始备份仍由所有者在本地保管，不在仓库内。

活动限制第三方工具时，不应使用助手参与该活动。出现验证、风控或账号异常，请按官方流程处理。不要修改程序来规避限购、验证或系统安全设置。

## 开发者构建

Windows 10/11、PowerShell 7、JDK 17 或 21、官方 Android SDK Platform 35 与 Build Tools 35.0.0。把 SDK 放到不含中文或空格的路径，避免部分工具识别路径失败。

```powershell
pwsh -NoProfile -File tools/build.ps1 -BuildTools D:/AndroidSDK/build-tools/35.0.0 -AndroidJar D:/AndroidSDK/platforms/android-35/android.jar -Jdk D:/Java/jdk-21
node tools/privacy-check.mjs
```

构建结果在 `dist/`。首次构建会在本机用户目录的 `AppData/Local/SaleStartAssistantSigning` 生成自己的签名密钥和 Windows 当前用户保护的密码文件，限制访问权限。它们不进 Git。备份和更新规则见开发说明。

可选的 `tools/make-manual.py` 从仓库说明生成 PDF，需要 Python、ReportLab 和 Windows 宋体字体；这一步不影响 APK 构建。

本项目不是微信小程序，也不是跨平台网页 App。源码采用 MIT 许可；不包含 B 站商标、第三方打包引擎或原实验抓取的网页代码。软件许可不等于平台活动授权，亦不免除依法应承担的责任。
