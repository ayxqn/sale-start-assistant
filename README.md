# 开售小助手

浅蓝色的 Android 小应用：登录自己的 B 站账号，启动后在后台等待活动开售，创建 178 元套餐订单，再由你到官方收银台选支付方式并付款。

**不是“只打开页面”的旧版本。2.0 已加入独立登录、活动校时、后台下单和结果日志。** 但新 APK 的真实开售与收银台全链路还没有验证，现作为预发布版提供。原手机脚本的成功记录不能代替新 APK 的实测。

## 下载与使用

普通用户只需要 [下载 APK](https://github.com/ayxqn/sale-start-assistant/releases/download/v2.0.0/sale-start-assistant-2.0.0.apk)。[完整发布页](https://github.com/ayxqn/sale-start-assistant/releases/tag/v2.0.0) 还提供 PDF 手册、源码包和校验文件。

1. 安装并阅读首次说明；仅 Android 8.0+，不支持 iPhone / iOS。
2. 在本应用打开的 B 站官方页面登录，点“已完成登录，核对并保存”。
3. 允许通知，将电量设置为“不受限制”。小米等系统可能还需允许后台自启动、锁定最近任务。
4. 开售前几分钟点“启动”。程序自动读取下一场时间、校准时差、核对固定的 178 元套餐；可以放到后台。
5. 出现订单通知后，点通知或“订单 / 去付款”。在官方收银台核对商品、金额、账号，再自行选择付款方式。

不用 AutoJs6、Root、电脑、ADB、配置文件或自行填商品编号。不要同时运行旧脚本或另一份抢购工具；不同程序不共享防重复记录。建议先在“使用说明”中做 20 秒演练，演练不联网、不下单。

## 会用到什么数据

应用会处理自己的登录会话、账号标识、昵称和必要订单参数，并在本机使用 Android Keystore + AES-GCM 加密保存。没有开发者服务器、广告或统计上报。登录与下单会连接官方服务，不是完全离线程序。

付款由官方 App / 浏览器处理；本应用不收集支付密码、银行卡、短信或指纹信息，不替你确认付款。会话和收银台签名仍是敏感数据，不要转发给别人。不能据此承诺“绝对无风险”或“任何情况下都安全”。

## 出问题能看什么

首页显示任务状态；“结果与报错日志”记录登录过期、活动/套餐变化、售罄、验证限制、网络异常、未知订单结果与系统中断等。日志不写 Cookie、完整订单号或支付签名。可以自己导出、查看或清空。

只有原程序已识别的“尚未开售”和特定“活动太火爆”无订单回复允许继续串行请求；遇到验证码、限流、售罄或结果不明就停止，不绕过限制，不并发刷单。结果不明时请先看官方订单，不要清空数据重来。

## 目前验证范围

- 77 项合成响应规则检查通过；没有发起真实订单。
- Android 16 真机安装、官方登录保存、保留登录的覆盖更新、浅色界面和一次 20 秒后台演练通过。
- APK v2/v3 签名通过；源码和发布范围做了凭据检查。
- 加密存储专项测试包被手机阻止安装，专项测试未执行。
- 新 APK 真实开售下单、收银台支付交接、跨账号实测、多机型、长时间锁屏/Doze 尚未完成。

本应用只适配当前“萌节十周年”178 元超大年度套餐，不保证买到或长期可用，与 B 站无官方合作。活动规则不允许辅助工具时不要使用。
