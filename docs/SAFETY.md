# 安全与隐私核实说明

[项目首页](../README.md) · [文档导航](README.md) · [安装与下载](DOWNLOADS.md) · [隐私政策](PRIVACY.md) · [安全说明](../SECURITY.md)

这份说明针对原始 `sale-start-assistant-1.0.0.apk` 和对应源码，核实日期为 2026 年 9 月 30 日。他人修改、重新签名或添加功能后的同名文件不在本次核实范围内。

## 已核实的事实

| 项目 | 核实结果与范围 |
| --- | --- |
| 安卓权限 | 源码安装清单与已构建 APK 均没有权限申请，包括联网、无障碍、截图、外部文件、定位、通讯录、相机和麦克风权限。清单没有后台服务、广播接收器或数据提供器。 |
| 联网与域名 | 应用源码没有 HTTP 客户端、WebView 或自行联网请求。输入规则只接受 `https://www.bilibili.com/blackboard/` 和 `https://m.bilibili.com/blackboard/` 开头的活动页，拒绝分享参数、支付链接和非官方域名。 |
| 页面交接 | 通过 Android Intent 把公开活动链接交给大陆版官方 B 站 App；打开失败时，由用户选择是否用浏览器查看。官方 App 和浏览器可能联网，按各自政策处理数据。实际跳转效果尚未通过运行测试。 |
| 账号和支付 | 没有登录框，没有读取账号、Cookie、短信、订单或支付资料的代码，也没有自动下单、付款、接口重试或验证码处理。相关操作留在官方 App，由用户完成。 |
| 数据保存与上传 | 仅用本机私有 SharedPreferences 保存活动名称、公开链接、时间和已读说明。没有数据上传、统计或崩溃上报代码，不保存运行日志。设置没有额外加密，不要填写密码或个人资料。 |
| 广告和第三方 SDK | 原生 Java 构建，没有第三方运行库、广告、统计、远程配置或自动更新 SDK。源码和 APK 文件组成已检查。 |
| 删除与备份 | 提供“清空本地设置”；卸载会清除助手自己的数据，不删除官方账号和订单。安装清单禁用应用备份；Root、入侵和厂商特殊迁移仍是限制。 |
| 签名与文件校验 | 1.0.0 APK 的 v2、v3 签名验证通过；APK、手册和源码包的 SHA-256 与本地发布校验记录一致。私钥、密码、旧账号会话和订单没有包含在这些发布文件中。 |

核实所依据的源码是 [安装清单](../app/src/main/AndroidManifest.xml)、[界面与流程](../app/src/main/java/io/github/ayxqn/salestart/MainActivity.java)、[链接与时间规则](../app/src/main/java/io/github/ayxqn/salestart/SalePolicy.java) 和 [构建脚本](../tools/build.ps1)。APK 的准确文件名、校验值与签名证书指纹见 [安装与下载说明](DOWNLOADS.md)。

## 已做的检查

Java 和资源编译、APK 打包、30 项不联网也不购买的链接与时间规则检查、APK 签名验证、安装包权限检查，以及源码隐私扫描。另检查了源码包的文件列表和 PDF 的可提取文字、元数据。自动扫描和人工检查都不能证明没有所有漏洞或恶意行为。

**没有做第三方杀毒平台扫描或独立安全审计，也没有把文件上传到第三方扫描网站。** 不据此写“绝对无毒”“零风险”或“100% 安全”。SHA-256 和签名验证用于来源与完整性核对，不是无病毒证明。

## 还没有验证的内容

没有完成这份新 APK 的真机或模拟器实际运行验收，包括安装、首次说明、真实界面、锁屏与后台行为、官方 App 跳转、多机型兼容及升级。因此仍标为内测。代码设计和电脑上的规则测试不能代替这些运行检查。具体清单见 [测试与验收](TESTING.md)。

没有真实下单或付款测试，也不承诺库存、资格、活动有效性或购买成功。活动禁止辅助工具时不要使用。

## 下载时注意什么

从原 [发布页](https://github.com/ayxqn/sale-start-assistant/releases/tag/v1.0.0) 取同名 APK，核对版本和校验值。不要关闭系统防护来安装；若系统提示安全风险、证书异常或文件损坏，停止安装。不要把密码、Cookie、付款链接或个人截图发到公开 Issue。

需要安全反馈时按 [SECURITY.md](../SECURITY.md) 处理。官方 App、浏览器和付款平台的隐私情况，需要分别阅读它们的说明，不能由助手作安全保证。
