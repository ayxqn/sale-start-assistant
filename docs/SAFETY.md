# 安全与隐私核实摘要

当前 APK 2.0 不同于早期无网络的 1.0。它需要官方登录、网络请求和后台服务，会处理个人登录会话及订单参数。完整说明见 PRIVACY.md 和仓库 SECURITY.md。

已查看本项目源代码、声明权限、依赖清单和发布文件范围：未加入开发者后端、广告/统计 SDK、远程命令执行、无障碍控制、截图读取或自动确认付款。账号和订单参数加密保存在本机，日志不含原始凭据。

这不是独立安全审计、查毒报告或零风险承诺。Android 系统、WebView、官方网页、第三方库、被篡改的安装包和设备被入侵仍可能有风险。仓库开源和签名正确只能提高可核对性，不能保证没有任何漏洞。

每次启动都可能创建真实订单。若遇到“结果不明确”，请到官方订单页核对，不要直接重试或清空数据。不要与旧脚本同时运行。

新 APK 的登录、短时后台和界面经过实测；真实下单与收银台交接仍未验证。旧程序成功日志只证明旧程序当时创建过订单，不能取代新版本验收。
