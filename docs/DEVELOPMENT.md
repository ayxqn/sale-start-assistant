# 从旧脚本到安卓应用

## 第一步 确认需求和边界

先说清楚程序要替用户做哪一步，再动手写代码。本项目只负责倒计时和进入官方页。下单、付款和验证留在官方 App。这样不需要处理账号密码，也不用维护不稳定的内部购买接口。软件是 Android APK，不是微信小程序，不兼容 iOS。

旧实验针对一次具体的限量套餐，包含电脑扫码登录、手机加密导入、内部接口下单、微信收银台交接和大量测试入口。不能只删一个账号 ID 就拿给其他人用。最终版独立重写，把那些特定活动、账号会话和订单状态全部移出发布范围；原始备份留在所有者本地。

## 第二步 画出用户操作顺序

首次说明 → 填公开活动链接 → 打开官方页核对本人账号 → 设北京时间 → 确认开始 → 前台倒计时 → 到点打开一次 → 官方 App 内手动购买。

每一个按钮都要有明确作用。只保留开始、停止、检查页面、十秒演练、说明和清空设置；不展示内部错误码、测试下单菜单、校时样本或账号导入选项。

## 第三步 把数据说清楚

本项目只需要活动名称、链接和时间，使用 Android 私有 SharedPreferences 保存，不建立用户数据库。公开活动链接也应做校验，避免把 Cookie 或支付参数存进去。账号由用户在官方 App 登录和切换，应用不读取或证明其登录身份，因此每次使用仍需本人核对。

## 第四步 写代码并处理意外情况

MainActivity 管界面和前台流程；SalePolicy 管链接、时间和时钟变化校验。两者分开，便于在电脑上测试核心规则。倒计时使用单调时钟推进，发现手机墙上时间与进度相差超过两秒便停止。离开前台、锁屏和销毁界面时清理任务。

只有倒计时正在运行时才保持屏幕亮着。成功请求打开页面不等于页面已显示，所以文案不能写“购买成功”。找不到官方 App 时提示用户，自行确认是否用浏览器查看，不绕过系统限制。

## 第五步 测试

电脑可检查非法链接、时间边界、倒计时数学、签名、权限和源码中的隐私内容。手机要检查安装、首次说明、页面跳转、十秒演练、停止、后台取消、锁屏、来电、旋转、大字体、清空设置和卸载。测试时不需要真实购买。完整列表见 TESTING.md。

能编译只能证明代码通过编译，不代表每台手机都能正常跳转，更不代表抢到限量库存。没有通过真机验收的版本应标“内测”，避免让用户误解。

## 第六步 构建和签名

开发环境使用 Windows 10/11、PowerShell 7、JDK 17 或 21、官方 Android Platform 35 与 Build Tools 35.0.0。下载官方工具并按官方包元数据核验，遵守它们自己的许可。SDK 尽量放在纯英文路径。

tools/build.ps1 会先测试，再编译资源和 Java 源码，生成 dex，打包、对齐、签名，最后验证签名并输出 SHA256SUMS.txt。没有联网运行库或隐藏的账号文件要手工复制。构建结果在 dist，构建中间文件在 build。

首次构建会在当前用户的 AppData/Local/SaleStartAssistantSigning 创建签名私钥和 password.dpapi。密码受 Windows 当前用户保护，目录只授权当前用户和 SYSTEM。别上传这两个文件。更换 Windows 账号或重装后，DPAPI 文件可能不能解密；应另做受控的离线备份和密钥恢复方案，密码不得写进代码或公开仓库。相同包名的更新必须使用原签名，否则不能直接覆盖安装。密钥丢失或泄露时，暂停发布并评估换包名或应用商店签名恢复，而不是随便覆盖密钥。

## 第七步 整理仓库和发布

源码、使用说明、隐私政策、安全说明、MIT 许可、版本变化和测试清单进入 Git。旧登录文件、订单、截图、抓取网页、安装引擎、签名私钥和中间结果不进入 Git。先运行 privacy-check.mjs，再人工看一遍所有待上传文件和提交历史；自动扫描不是安全认证。

本次仓库默认私有。APK、校验文件和用户手册通过 Releases 提供，标为预发布内测版。下载页必须写清安卓版本、活动适配范围、主要功能、删除的功能、测试状态和已知限制。之后如果要公开仓库，应先确认待公开资料确实不含个人信息，公开本身是另一次分享决定。

## 第八步 发布后维护

检查官方入口或系统变化，记录问题，修复后提高版本号、重新测试并用相同密钥签名。每次变更新增权限、联网、账号或统计功能时，都要同步修改隐私政策、首次说明和商店数据申报，不能沿用旧承诺。

若进一步上架应用商店，还需按当时、目标地区和渠道的要求确认开发者资格、签名、备案或登记、隐私政策入口、数据安全申报、年龄分级、应用图标名称、联系渠道和平台授权。本次未办理或承诺取得这些手续；私有 GitHub 预发布不等于完成商店合规。具体法律义务需要按适用地区核实，不把本说明当法律意见。
