# 2.0.0：独立登录与后台创建订单

这是 Android 独立 APK，不需要 AutoJs6、电脑、服务器或自己填写账号参数。首页为浅蓝可爱风，采用圆润中文字体和 22 / 33 主题同人装饰。

在应用内的 B 站官方页面登录，核对并保存自己的账号；开启通知、设置电量不受限制，点启动。程序读取官方下一场时间、自动校时并核对 178 元套餐，到点按迁移后的规则串行请求创建订单。订单生成后，通过通知或首页“订单 / 去付款”进入官方收银台，支付方式及付款由本人确认。

新 APK 已完成构建、签名校验、77 项离线合成响应检查、手机安装、官方登录保存及保留登录的覆盖更新、前台界面检查和一次 20 秒后台演练。原手机 V2.4 脚本存在已核实的真实订单创建成功记录；它不等于新 APK 已完成同样的全链路验证。新 APK 的真实开售下单、收银台及微信/支付宝交接仍未验证。Android 加密存储专项测试包被手机阻止安装，该专项测试未执行。

因此按预发布版提供。仅适配当前 178 元活动，不保证库存、资格、后台存活或平台接口持续可用。不可绕过平台限制；验证/限流/结果不明时停止自动提交。不要同时运行旧脚本和本应用，二者不共享防重复记录。

会话和必要订单参数使用本机 Android Keystore 加密保存；没有开发者后台或广告统计上报。不收集支付密码、银行卡、短信或生物识别数据。但会处理账号会话和订单签名等敏感信息，不能说它“完全不接触个人信息”或“绝对零风险”。

Android 8.0+；不支持 iOS。下载只需要 APK，PDF 和源码包是可选材料。完整说明见仓库手册和应用内“账号与数据”。
