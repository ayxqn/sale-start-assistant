# 使用手册

## 先确认适不适合你

这不是微信小程序，是一个只在安卓运行的 APK。支持 Android 8.0 及以上，不兼容 iOS。只适配 B 站“萌节十周年”178 元超大年度套餐，不是任意商品的通用抢购器。权益、资格、价格和活动规则以官方页面、订单为准。活动结束后，不要期待它自动寻找替代商品。

本版包含自动创建订单功能。点“启动”就是授权使用当前账号参与这场 178 元活动；如果活动已经开售，可能立即请求创建订单。它不会替你选择支付渠道，也不会自动确认付款。

## 第一次使用：只需 APK

从仓库 v2.0.0 发布页下载 APK。安装可能需要给你使用的浏览器或文件管理器一次“允许安装未知应用”权限，安装后可关闭。不要关闭手机安全防护；遇到异常签名提示应停止安装并核实。PDF、源码 ZIP、校验文件都不是 App 的运行依赖。

首次打开先阅读说明。应用需要联网、通知和后台运行能力，不需要无障碍、截图、定位、通讯录、短信、相机、麦克风或外部文件权限。

## 在官方页面登录

点“登录 B 站”，本人完成官方页面的登录与验证，再点“已完成登录，核对并保存”。密码或验证码不要发给开发者，也不要粘贴到聊天中。只有官方账号核对通过才会保存会话。

这是本应用自己的登录状态，不会读取手机 B 站 App 的私有文件，也不直接沿用开发者账号。手机 B 站 App 和助手可能登录不同账号；付款前仍要核对官方收银台显示的购买对象。应用内账号区显示昵称和账号尾号，换账号请点“重新登录 / 换账号”。任务运行时不能换账号。

会话过期后需要再次登录。“只登录一次”不是永不过期的承诺。

## 后台设置与演练

允许通知，将电量设置为“不受限制”。不同手机入口不同，小米等系统还可能需要允许自启动和锁定最近任务。不要强行停止应用、用清理工具关闭任务或同时运行旧脚本。

在“使用说明”中选择“20 秒后台演练”，回桌面等待通知。演练不联网，也不下单，只检查短时后台运行与通知。通过演练不等于长期锁屏也一定成功。

等待期间会保持处理器唤醒，可能增加耗电；建议开售前几分钟启动，不要提前一整天挂着。

## 正式启动后

程序读取官方未来 24 小时内的可参加场次。临近开售会核对登录、采集官方时间、刷新套餐参数，在单调时钟上等待提交。你不必手工填时间、商品编号、Cookie 或 CSRF。

价格和套餐身份任一项改变都会停止，不会擅自改买同价商品。已开售时走立即准备路径，不额外等待校时采样。只会串行发送，上一笔结果明确后才决定是否下一笔。

成功取得订单后，首页显示“订单已创建”。应用在前台时会请求打开官方收银台；在后台时以通知提醒，你需要点一下通知。Android 可能不允许后台强行弹出付款界面，不能承诺锁屏时自动切到微信。

在收银台检查套餐、金额、购买账号、支付期限以及是否有续费约定，再选择官方支持的渠道付款。最终支付成功、退款和权益到账以官方记录为准。助手不查询支付结果，也不代付。

## 停止与重启

“停止任务”只阻止后续工作，已经发出的请求不能撤回。系统终止进程、重启手机或强行停止后不会偷偷恢复下单。回到应用看中断提示，先检查官方订单。

本应用保存每个账号、活动及北京时间日期的防重复记录。出现订单或结果不明后，同场重新启动会拦截。不要通过清空数据绕开它。旧 AutoJs 程序、另一台手机、卸载后重装均不共享这份记录，仍有重复下单风险。

## 没抢到时怎么看原因

- 登录失效：重新登录，核对显示的账号；不会因此自动补单。
- 无可参加场次：可能活动结束、已购、资格不足或下一场尚未发布，以官方页面为准。
- 套餐不一致：价格或商品编号变化，需更新适配；不能自己改几个数字就继续。
- 已售罄：官方明确没有库存，不保证补货。
- 验证或限制：停止使用，去官方页面自行处理，不绕过验证码或限流。
- 网络超时、断网或未知结果：可能服务器已收到请求，先核对官方订单；不能断言“没有下单”。
- 校时样本不一致：未准备提交，请检查网络和手机时间。
- 订单已创建但本地保存失败：直接去官方订单页找订单，不要再次启动。
- 后台中断：检查电量、通知、自启动与系统清理；不能保证所有机型都不杀后台。

日志中的往返耗时和调度延迟只是客户端观测，不是精确的服务器到达时间。错误码有助定位，不代表能知道服务器内部的一切原因。

## 退出、清空、卸载

“账号与数据 → 退出当前账号”删除登录会话和本地付款入口，保留加密的防重复记录。不会退出官方 B 站 App，也不会取消官方订单。

“清空本应用全部数据”还会删除日志与防重复记录；卸载也会删除应用私有数据。官方订单和平台账号不受影响。清空或卸载前，请处理未完成订单。分享出去的日志不会被本机清空操作收回。

更新同签名 APK 通常可以保留登录状态。不要安装来路不明、签名不同的修改版；更换维护者或签名时需特别核实。
