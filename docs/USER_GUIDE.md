# 使用手册

[项目首页](../README.md) · [文档导航](README.md) · [安装与下载](DOWNLOADS.md)

## 先准备好

安卓 8.0 或更高版本的手机、官方大陆版 B 站 App，以及本人账号和正常网络。助手本身不联网，但活动页和支付需要网络。iPhone、iPad、iOS、其他购物平台、B 站国际版和 HD 版不在本版适配范围内。鸿蒙等系统只有在确实能运行本 Android APK 时才可能使用，不能承诺原生兼容。

这不是无人值守抢购。你需要在旁边看着手机，到点后自己下单和付款。助手不替你接受协议、处理验证码、修改付款方式或完成指纹验证。

## 安装

普通用户只需下载并安装 [sale-start-assistant-1.0.0.apk](https://github.com/ayxqn/sale-start-assistant/releases/download/v1.0.0/sale-start-assistant-1.0.0.apk)。不需要源码、Python、ADB、SDK、服务器或外部配置文件。手册和校验文件可按需要下载；完整下载入口及校验值见 [安装与下载说明](DOWNLOADS.md)。

核对原发布页的 APK 和 SHA256SUMS.txt。安卓“允许此来源安装”只给当前下载或文件管理应用，完成后关闭即可。别把所有来源都放开。若系统报告安全风险、证书异常或文件损坏，不要关闭系统防护去强装。单位或学校管理的设备，应遵守设备管理要求。

## 第一次使用

先做一次“10 秒演练”。完成后再填链接，点“先打开官方页，检查账号”。如果这一步没打开正确页面，先解决跳转问题，不要直接开始正式等待。

活动链接必须是 https://www.bilibili.com/blackboard/ 或 https://m.bilibili.com/blackboard/ 开头的公开活动页。分享链接里的问号、井号及之后的参数要去掉。本版不接受短链接、私有收银台链接或其他站点，以免把账号资料或错误地址存进去。

在官方页核对账号和资格，尤其是实名、年龄、地区、会员状态、限购和已参加记录。商品价格相同不代表套餐相同。赠品需要在哪个平台领取、什么时候过期、退款后权益怎样处理，都应先看清楚。有自动续费提示时，由本人决定，不要只看首期价格。

回到助手，选择开售日期和时间，按北京时间填写，秒数固定为 00。打开手机自动日期和时间；不要在倒计时中修改系统时间。开售前两小时内启动，看到“正在等待”才算运行。

## 等待和付款

让助手留在前台，手机解锁并亮屏，保持电量和网络稳定。倒计时期间应用会让屏幕保持亮着，停止后解除，长时间使用会耗电、发热。切走、锁屏、来电或系统清理都可能停止任务。应用不安装后台服务，不会悄悄重新启动。

到点只发起一次官方页面打开请求。等页面实际显示后再购买，付款前核对账号、商品、金额、商户和权益。创建订单不等于支付成功；支付失败或结果不明时，先在官方订单中核对，避免重复买。活动按钮未更新，按官方 App 的正常方式刷新或重新进入。

## 常见问题

**为什么开着助手却没动静？** 可能只打开了界面，没有点“开始倒计时”，或者后来切到了后台。看状态文字，不要只看应用图标。

**不用电脑也能用吗？** 能。APK 安装后独立运行，电脑和 USB 不参与使用。需要正常网络的是官方活动和支付。

**换成别人的账号会不会用到开发者的信息？** 不会。账号只在官方 App 里换。助手没有导入账号功能，也没有预装开发者登录信息。

**为什么没有跳到 B 站？** 确认安装的是大陆版官方 App；新版入口或系统跳转设置可能改变。助手会提供浏览器入口，也可以自行打开官方活动页。它不会帮你修改系统安全设置。

**手机时间准确就一定抢得到吗？** 不会。库存、资格、服务器负载、网络、页面加载和本人操作都可能影响结果。这个版本没有活动服务器校时，也没有自动购买。

**怎么彻底不用了？** 先停止倒计时，点“清空本地设置”，再卸载。官方账号、订单和支付记录继续由官方应用管理。
