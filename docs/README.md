# 资料导航

- USER_GUIDE.md：第一次安装、登录、后台设置、下单、付款、报错和清空。
- PRIVACY.md：数据种类、联网对象、加密、日志和权限。
- ../SECURITY.md、SAFETY.md：保护措施、剩余风险、签名和反馈注意事项。
- DEVELOPMENT.md：从旧脚本到 APK 的整个开发过程、构建和发布步骤。
- LEGACY_COMPARISON.md：原流程哪些照搬、哪些改变，旧成功证据的边界。
- TESTING.md：已通过、未执行、尚未验证的项目。
- ARTWORK.md：同人插画提示词、生成方式、字体与授权说明。
- DOWNLOADS.md：哪些附件要下载，哪些不用。
- RELEASE_2.md：2.0 发布说明。

app 是应用代码及资源；tests 是离线测试；tools 是构建/下载依赖/手册工具。dependencies.lock.json 固定依赖校验值。build、dist、output、dependencies 和 test-dependencies 是本地生成目录，默认不进 Git；发布附件从审核后的 dist 文件逐一上传。
