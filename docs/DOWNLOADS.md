# 下载和安装

普通安卓用户只需要 sale-start-assistant-2.0.0.apk。完整地址：https://github.com/ayxqn/sale-start-assistant/releases/tag/v2.0.0

打开发布页下方 Assets，下载 APK，安装后按应用内说明登录自己的账号。只支持 Android 8.0+，没有 iPhone / iOS 版本。无需电脑、AutoJs6、Root 或无障碍。

可选附件：

- sale-start-assistant-manual-2.0-zh-CN.pdf：A4 使用、隐私、开发与测试手册。
- sale-start-assistant-source-2.0.0.zip：对应源码，普通使用无需下载。
- SHA256SUMS.txt：文件 SHA-256 校验值。

本版是预发布版，新 APK 尚未完成真实下单到付款的全链路测试。不要把安装成功或登录成功理解为保证抢到。

不要下载 output/device-selftest.apk：这是开发者独立离线测试包，不随发布。不要下载或索要旧账号导入文件、签名私钥、Cookie 和付款记录。

只从本仓库或经核对的可信发布渠道下载安装。不要为安装关闭系统安全保护。原签名覆盖更新会保留本地数据；签名不一致时先核实来源，不要直接卸载后硬装。卸载会失去本地防重复记录。
